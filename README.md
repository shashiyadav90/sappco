# SAPPCO React Website

A responsive single-page React + Vite conversion of the supplied SAPPCO HTML website, with additional motion effects and a mobile navigation menu.

## Run locally

1. Install Node.js (18+ recommended).
2. Open this folder in VS Code / terminal.
3. Run `npm install`
4. Run `npm run dev`
5. Open the local URL shown by Vite.

## Before going live
- Update `hello@sappco.in` and add verified phone/address details.
- Replace the text SAPPCO brand mark with the official logo if available.
- Add actual founder/team photos and profiles, college/client/case-study names.
- Confirm package wording and pricing (currently uses Request Proposal / non-price labels).
- Connect the enquiry form to your backend, CRM or email service. The current form is a front-end demo only.

The page uses Google Fonts via an external import; remove that import if you prefer locally hosted fonts.
